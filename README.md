# Smart Auto Mouse Free

**Automate repetitive mouse and keyboard tasks on Windows—without writing code.**

Smart Auto Mouse Free helps you record and replay everyday desktop actions. Build a simple macro, repeat it when needed, and save time on routine work.

## Features

- Record and replay mouse and keyboard actions
- Create macros with up to 30 steps
- Repeat loops up to 10 times per run
- Use up to 2 image-find actions in a macro
- Use 1 Smart Wait action in a macro
- Pause automatically when you take manual control of the mouse
- Simple interface designed for everyday users

> **Important:** The computer screen must be active and visible while an automation is running. Smart Auto Mouse does not click on a screen that is turned off or unavailable.

## Download

The Windows installer will be available on the [Releases](https://github.com/ahmetruzgar/Smart-Auto-Mouse-Free/releases) page.

Download the latest `SmartAutoMouseFree_Setup_1.6.0.exe` file, open it, and follow the installation steps.

## Free and Pro

The Free edition is designed for short, basic automations. Smart Auto Mouse Pro is intended for longer and more advanced workflows, with unlimited actions and loops, scheduling, conditional actions, advanced image recognition, error handling, macro backup, multiple languages, and other professional features.

## Getting Started

1. Download the latest installer from **Releases**.
2. Install and open Smart Auto Mouse Free.
3. Create or record your automation steps.
4. Review the sequence before running it.
5. Start the automation and keep the required application visible.

## Safety

Always review a macro before running it. Do not use automation for destructive actions, sensitive financial transactions, password entry, or tasks that violate a website's or application's terms.
